For the most part, you can write equations normally. 

If you need specific symbols, use a backslash

```latex
\sigma % lowercase sigma
\Sigma % uppercase sigma
\infty % infinity
```

If you want to subscripts, or superscripts, that also needs conditions:
```latex
a^{2}
b_{2}
```

Integrals require both:
```latex
\int^{0}_{\infty} 
```

$$ 
\int^{\infty}_{0} \frac{a}{b} db
$$
